# An Arcade app made in Godot 

### This app is made for showcasing graduating students game projects at GradFest 2026 @ Norwich University of the Arts

Developed as a lightweight GUI App in Godot that launches game projects as seperate processes. Tracking their process as to not allow mutiple open at once. 
Keyboard shortcuts and debug console build features are for invigilators to diagnose any issues on site.
